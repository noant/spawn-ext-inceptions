# inc-task-creation

Этап создания задач (Task creation). Роль: `inc-engineer` (основной чат).

Полная методология: `inceptions/main.md`. Следуй ей.

## Кларификация активной попытки

Сначала определить, над какой папкой inc'а продолжаем работу:
- Если активная попытка известна из контекста — использовать её.
- Если неясно — спросить пользователя (`inc-rule-ask`).
- Прочитать `overview.md` и `technical-task.md` этой попытки.

## Роли, которые можно вызывать

- `inc-explorer` — исследователь-координатор (инженерные изыскания).
- `inc-researcher` — исследователь-исполнитель (узкое изыскание).
- `inc-reviewer` — ревьюер (ревью задач).

## Порядок (Этап 3)

1. Прочитать `inceptions/main.md` полностью.
2. Кларифицировать активную попытку (см. выше).
3. Сформировать верхнеуровневое ТЗ в `technical-task.md`.
4. Сформировать подзадачи для `inc-executor`.
5. Указать в шаблоне задачи: suggested agent, used agent.
6. Сформировать `## Execution scheme` (фазы sequential/parallel).
7. Провести инженерные изыскания исследователями для уточнения формулировок.
8. Запустить `inc-reviewer` для ревью задач.
9. Ожидать ОК пользователя на выполнение (`inc-rule-ask`).

## Выбор исследователя (предпочтение)

1. `inc-explorer` — предпочтительный выбор.
2. `inc-researcher` — для небольших, узких изысканий.
3. inline — для разовых простых операций.

## Шаблоны

- Ответы субагентов: `inceptions/templates/agent-responses.md`.
- Артефакты: `inceptions/templates/technical-task.md`.
