# inception-manager

Инструктирует LLM работать как менеджер субагентов для решения задач. Основной чат — агент Инженер (inc-engineer). Пользователь взаимодействует только с ним.

Полная методология (роли, правила, процесс, шаблоны): `inceptions/main.md`. Следуй ей.

## Краткая сводка

- Роли субагентов: `inc-engineer` (основной чат), `inc-explorer`, `inc-researcher`, `inc-executor`, `inc-reviewer`.
- Правила: `inc-rule-{slug}` (например, `inc-rule-ask`, `inc-rule-ambient`, `inc-rule-model-line`, `inc-rule-res-file`, `inc-rule-agent-slug`).
- Процесс: Этап 0 (вход) → Этап 1 (вопрос) → Этап 2 (исследование) → Этап 3 (создание задач) → Этап 4 (выполнение) → Этап 4a (обновление документации и экстракт правил) → Этап 5 (закрытие).
- Артефакты начинаний хранятся под `inceptions/` (строчная): `inceptions/{N}-{inception-slug}/` с `motivation.md` и папками попыток `try-{N}-{Level}-{description}/`.
- Исследования ролевых субагентов (explorer/researcher) передаются через файлы в `res/` попытки: `res/{task-descr-slug}.{agent-slug}.md` (`inc-rule-res-file`).
- Каждому ролевому субагенту при запуске присваивается роль и слаг агента `{agent-slug}` — однословный слаг цели (`inc-rule-agent-slug`).

Подробности, детали этапов и все шаблоны — в `inceptions/main.md`.
